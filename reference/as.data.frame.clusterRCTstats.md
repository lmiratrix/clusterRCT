# Cast cluster RCT info result to data.frame

Cast cluster RCT info result to data.frame

## Usage

``` r
# S3 method for class 'clusterRCTstats'
as.data.frame(x, row.names = NULL, optional = FALSE, ...)
```

## Arguments

- x:

  the clusterRCTstats object to covert

- row.names:

  NULL or a character vector giving row names (see
  [`as.data.frame`](https://rdrr.io/r/base/as.data.frame.html))

- optional:

  passed to [`as.data.frame`](https://rdrr.io/r/base/as.data.frame.html)
  (unused)

- ...:

  additional arguments (unused)
